# 1vs1 데스매치 · 2026-09-20

승인 범위: 연습방 입구를 데스매치로 교체. 기존 4인 배틀 보존. 가상 골드 1%당 20,000G, 5라운드, 210봉 분석 + 30봉씩 90봉 공개. 진입 방향 선택과 30/60봉의 GO/STOP으로 세 번 판단한다.

결정: GO는 현 배율 유지, 레이즈는 1.5/2/3배 중 더 높은 배율을 제안한다. 상대 CALL 전에는 적용하지 않는다. 각 체크포인트에서 재레이즈 없이 한 번 제안/응답한다. STOP/포기는 현재 합의 배율 × 20,000G를 상대에게 준다. 양쪽 보유 골드 중 작은 금액을 상한으로 한다. 방향이 같으면 공개 완료 시 무승부. 반대 방향이면 최초 진입 대비 등락률 × 단가 × 합의 배율을 이긴 쪽으로 이전한다.

제약: 현재 저장소에는 서버 지갑/정산 함수가 없다. 이번 배포는 명시적으로 표시된 봇 상대와 기기 내 가상 골드 정산이다. 실제 이용자 간 매칭/이전은 제공하지 않으며, 서버 권한 검증/공동 지갑 트랜잭션 구현 전에는 활성화하지 않는다.

구현: 별도 순수 규칙 모듈, 기존 지갑의 deathmatchActive에 경기/양쪽 잔고 저장, 라운드별 중복 정산 방지, 재접속 시 이어하기, 명시적 종료 시 현재 합의 판돈 포기. 다른 창 소유권/수정 버전 검사. 기존 battleActive와 동시에 열지 않는다. 봇은 공개된 봉과 무작위 값만 사용한다.

검증: 금액/배율/포기/콜/동일 방향/부족 잔고/중복 동작/5라운드/지갑 보존/재접속 테스트. 일반 배틀 회귀 검사. 모바일 가로/세로 및 데스크톱 DOM/화면 확인. 기존 리액션 재사용.

검토 반영: 종료 상태 저장과 지갑 반환을 원자적인 단일 snapshot으로 통합. 중단된 terminal 상태도 이어하기에서 복구. 동시 시작 시 실제 신규 경기 생성 여부를 잠금 안에서 판정하여 횟수 이중 차감 방지. 홈페이지 교환/구매/보상 및 구형 서바이벌 보상도 공통 지갑 잠금을 공유. 기존 동기식 4인 엔진은 경기 동안 잠금을 유지하고 종료 시 반환하며, 그 동안 다른 탭 교환은 재시도 안내.

로컬 QA: 8036의 격리 지갑에서 봇 레이즈/포기, 30봉 체크포인트, 두 라운드 결과, 새로고침 복구, 종료 후 40,000G 반환 확인. 8037 새 지갑에서 기존 4인 입장·종료 후 데스매치 이동 확인. 320×650, 390×700, 844×390, 768×700에서 조작부가 화면 안에 있고 수평 넘침 없음. 실제 사람 둘의 서버 거래는 이번 구현 대상에 포함되지 않았으며 UI에 봇을 명시한다.
