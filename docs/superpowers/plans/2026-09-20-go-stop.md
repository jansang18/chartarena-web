# Five-round GO / STOP Implementation Plan

**Goal:** Five rounds, each with entry, a decision after 30 candles, and a decision after 60 candles; settle automatically at 90. STOP locks that player's cumulative entry-to-exit result and leaves them watching.

**Architecture:** Preserve the shared wallet and chart renderer. Add deterministic checkpoint rules, a dedicated real 300-candle battle dataset, and version-six room synchronization. A confirmed entry/GO reserves the result through the next 30-candle endpoint, so leaving cannot undo a committed decision. Apply each round exactly once.

**Tech stack:** Plain JavaScript, HTML/CSS, Node tests, Firestore room snapshots.

**Spec:** User approval in this task: 210 historical candles + 90 future candles, five rounds, maximum fifteen decisions. Early STOP removes subsequent decisions for that round. Checkpoint timeout defaults to STOP. Direction and leverage stay fixed until the next round.
