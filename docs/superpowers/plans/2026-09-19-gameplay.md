# ChartArena Gameplay Expansion Implementation Plan

> **For agentic workers:** Execute the approved work in isolated file ownership: root battle/rules/integration, puzzle worker puzzle engine/UI/tests, daily worker daily engine/UI/tests.

**Goal:** Ship all six approved gameplay improvements while preserving owned cosmetics and existing progress.
**Architecture:** Pure battle, puzzle and daily rule modules plus the existing page engines. Battle wallet is ephemeral and equal; persistent gold receives completion rewards only. Daily first attempts persist separately from practice and use the existing authenticated score documents.
**Tech Stack:** Static HTML/CSS/JS, node:test, existing Firebase compat, existing chart/character assets.
**Spec:** User-approved brainstorm in this conversation, 2026-09-19.

## Global Constraints
- Keep existing storage keys and user-owned characters; new rules use versioned data.
- 5 battle rounds, 10,000 match-only points, one tactical power and one deliberate pass per match.
- Power (1.5× gains AND losses) and defense (0.5× gains AND losses) exclusive once per match.
- No guess at timeout: missed turn receives a fixed -200 match-point penalty, preserves pass, visibly explained.
- All submissions revealed after all human confirmations or common deadline; online score is derived identically for all participants.
- 4 question types and mixed boss; daily same 3 charts by Asia/Seoul date, first attempt only for ranking, practice unrestricted.
- Fake leaderboard entries forbidden. Offline rankings identified. No backend security widening.
